## 1. מטרה

לבנות אתר משלוחים חדש לרשת **עלינא בפיתה** על גבי הדומיין `alenabepita.co.il`, כך ש:

- לקוחות יוכלו להזמין משלוחים ישירות מהאתר (תחליף ל-Wolt וההזמנות הטלפוניות).
- המוצרים יסונכרנו אוטומטית מ-**Be'teavon** (המערכת שכבר עובדים איתה — לא בנייה שלנו).
- מועדון הלקוחות יתחבר ישירות ל-**TOPALENA.COM** (מקור אמת יחיד).
- בעלים יוכל לעלות מבצעים, ספיישלים, פופאפים ובאנרים בעצמו דרך אדמין וורדפרס.
- בהמשך — **ValueCard יוצא לגמרי** מהמערכת (חודש אחרי שהאתר עולה).

### מודל המועדון ב-TOPALENA (כבר קיים)

מצאנו בסכמת Prisma הקיימת (`apps/api/prisma/schema.prisma`):

```prisma
model Customer {
  phone               String
  name                String?
  visit_count         Int?      @default(0)
  coin_balance        Int?      @default(0)
  loyalty_tier        String?   @default("regular")
  last_visit          DateTime?
  marketing_consent   Boolean   @default(false)
  ...
}
model CustomerBenefit { ... }
```

לכן **אין צורך לבנות מועדון מאפס** — רק לחבר את האתר ל-API שכבר קיים.

## 4. רכיבים

### 4.1 וורדפרס + WooCommerce (תשתית)

- וורדפרס עצמאי על `alenabepita.co.il` (כבר קיים, ריק ממוצרים)
- WooCommerce מותקן
- Be'teavon מסנכרן מוצרים לכאן (מנוהל על ידיהם)
- ניהול ידני של: קומבו, ספיישלים, באנרים — דרך אדמין WP

### 4.2 פלאגין `Alena-TOPALENA-Bridge` (קוד שאנחנו כותבים)

פלאגין PHP חדש שמותקן בוורדפרס. אחראי על כל החיבור ל-TOPALENA דרך REST API.

**Endpoints שיצטרכו להתווסף ב-TOPALENA:**

| Endpoint | מטרה |
|---------|------|
| `POST /api/club/lookup` | קלט: טלפון. פלט: שם לקוח, נקודות, tier, הטבה זמינה |
| `POST /api/club/orders` | אחרי הזמנה: שולח טלפון, סכום, פריטים → עדכון visit_count + coin_balance |
| `POST /api/club/register` | לקוח חדש: יוצר Customer ב-TOPALENA + מטפל ב-marketing_consent |
| `GET  /api/club/benefits/:phone` | מחזיר הטבות פעילות ללקוח |

**אבטחה:**
- JWT עם API key פרטי שיושב ב-`wp-config.php`
- כל קריאה מהפלאגין חתומה
- Endpoint ל-`lookup` מוגבל ל-rate-limit (לא חשיפת מאגר טלפונים)

**Hooks ב-WooCommerce:**
- `woocommerce_checkout_order_processed` → שליחת ההזמנה ל-TOPALENA
- `woocommerce_thankyou` → הצגת נקודות נצברות
- `woocommerce_review_order_before_payment` → תצוגת מועדון בתשלום
- `user_register` → רישום ל-TOPALENA אם סומן "הצטרף למועדון"

### 4.3 אזורי חלוקה ודמי משלוח — **פלאגין מותאם** (Alena Delivery Zones)

**עדכון 2026-06-09:** הבעלים ביקש פוליגונים על מפת Google, לא מיקודים. זה לא קיים סטנדרטי ב-WooCommerce — בונים פלאגין PHP נפרד.

**ארכיטקטורה:**
- מסך אדמין חדש: "אזורי חלוקה" — בעלים מצייר פוליגונים על מפה אינטראקטיבית (Google Maps Drawing Tools), כל פוליגון מקבל: שם, צבע, דמי משלוח, מינימום הזמנה.
- כל פוליגון נשמר ב-WP option (`alena_delivery_polygons`) כ-array של geometries (lat/lng arrays) + מטא.
- שיטת משלוח חדשה ב-WooCommerce ("Alena Polygon Delivery") שכאשר לקוח מקליד כתובת בעמוד תשלום:
  1. ה-JS שולח את הכתובת ל-Google Geocoding API → מקבל lat/lng
  2. הצד השרת בודק (Point-in-Polygon) באיזה פוליגון הכתובת נופלת
  3. אם בפוליגון — מציג את שם הפוליגון, דמי המשלוח, מינ' הזמנה
  4. אם לא בשום פוליגון — "אין משלוחים לאזור הזה" + הצעה לאיסוף עצמי
- מפתח Google Maps API (חינמי עד 28,000 בקשות/חודש — מספיק)

### 4.4 מנגנון שעות פעילות — **פלאגין מותאם** (Alena Hours Engine)

**שעות שהבעלים נתן (2026-06-09):**

| שירות | יום | שעות פתוח |
|------|-----|-----------|
| משלוח | א-ה | 11:00 – 23:00 |
| משלוח | ו | 11:00 – 15:00 — **רק קטגוריית "חומוסייה זוהרה"** |
| משלוח | מוצ"ש | חצי שעה מצאת שבת – 23:30 (משתנה לפי לוח שנה!) |
| איסוף | א, ג, ד | 11:00 – 23:55 |
| איסוף | ה | 11:00 – 01:55 (למחרת בבוקר) |
| איסוף | ו | עד 15:00 |
| איסוף | מוצ"ש | עד 00:55 |

(שעות יום ב' ו-ב' עבור איסוף לא הוגדרו — מניחים זהים לראשון.)

**רכיבים:**
- טבלה ב-DB: `alena_hours` (service, day_of_week, open_time, close_time, category_filter?)
- API לזמני שבת: שילוב עם **Hebcal API** (חינמי) — לקבל יציאת שבת לראשון לציון כל שבוע
- Function `is_open(service, datetime)` — מחזיר {open: bool, message?: string, available_categories?: string[]}
- חסימת checkout אם מחוץ לשעות + אפשרות לתזמן הזמנה עתידית ("הזמנת ליום ה' ב-12:00")
- בשישי — סינון מוצרים: רק שמשויכים לקטגוריה "חומוסייה זוהרה" יוצגו / יותרו לקנייה


### 4.6 פופאפים וספיישלים

- פלאגין **Popup Maker** (חינמי)
- תרחישים נתמכים:
  - פופאפ "ברוכים הבאים" עם הצעת הצטרפות למועדון
  - פופאפ יציאה עם קופון
  - באנר עליון לספיישל היום
  - מודאל "חמין יום שישי" שמופיע רק בימי חמישי-שישי
- ניהול ע"י הבעלים, ללא צורך בקוד

### 4.7 עיצוב

- תבנית מותאמת בסגנון האתר החדש של עלינא (`alenabepita.co.il` הנוכחי — צבעים, פונטים, גלריה)
- בסיס: **Astra** או **Storefront** + Customizer
- RTL מלא, נגיש בסלולר
- ביצועים: WebP, lazy-load, cache (פלאגין WP Rocket או LiteSpeed Cache)

### 4.8 התראות

- **לבעלים:** הזמנה חדשה → SMS + Email (פלאגין: WooCommerce SMS Notifications)
- **ללקוח:** אישור הזמנה, "יצאנו עם המשלוח", "המשלוח הגיע" → SMS דרך ספק קיים (Inforu/Twilio)
- אינטגרציה עם מערכת ההתראות הקיימת ב-TOPALENA (Web Push למנהלים)
