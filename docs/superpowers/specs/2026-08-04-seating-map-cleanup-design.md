# מפת הושבה — ניקיון מסך + "העבר" בנייד + אקורדיון אזורים

תאריך: 2026-08-04 · קובץ: `src/pages/SeatingSetup.jsx` · המשך ל-`project_seating_map_redesign`

## הבעיה

מעל המפה יושבות **שלוש** שורות של chrome, ~22 פקדים:

1. `CardHeader` — "ניהול הושבה" + מפה גדולה / רשימה / מפה / הגדרות▾ / שמור
2. פס פעולות — הזמנה חדשה / הושבה מהירה / שבץ הכל / כל האזורים▾ / כלים▾ / חי / שעון
3. פס זום — −/%/+ / עדשה▾ / שורות▾ / נעילה / צבעים / יישר מפה / אלמנט / שרטוט / AI

רוב הפקדים האלה הם **כלי הקמה** שנוגעים בהם פעם בחודש, אבל הם תופסים מקום קבוע במסך שבשירות צריך להיות מפה ותו לא.

בנוסף: בנייד המפה מוחלפת ברשימת אזורים (`md:hidden`) — "המפה שהיא לא באמת מפה" — ושם אי אפשר להעביר אורח לשולחן אחר בלי לצלול לדיאלוג פרטי שולחן. ובורר השולחן בעריכת הזמנה הוא `<select>` נייטיב עם 57 שורות ו-`optgroup`, שקשה לקרוא בו.

## ההחלטות (אושרו ע"י הבעלים)

1. **למחוק את `CardHeader` לגמרי** — הכל עובר לפס אחד.
2. **פקדי זום צפים על פינת המפה** (כמו כל אפליקציית מפות), לא בפס.
3. **"העבר" יושב ליד השולחן ברשימת הנייד** — לא בפס העליון ולא בכרטיס שבמפה.
4. **בורר השולחן = אקורדיון אזורים**, לא `<select>`.

## מה נבנה

### 1. `src/components/seating/ZoneTablePicker.jsx` (חדש)

בורר שולחן שמונע מהנתונים האמיתיים (`tables`), לא מרשימה מקודדת כמו
`components/dashboard/TablePicker.jsx` שמשרת את התור בלבד.

```
props: tables, value, onChange, partySize, busyTableNumbers, allowNone, autoFocusSearch
```

- טריגר: כפתור שמראה את הבחירה הנוכחית ("701 · 1-2 סועדים" / "כללי — ללא שולחן").
- פאנל: חיפוש חופשי, ואז **שורת אקורדיון לכל אזור**: `{אזור} · {n} מתאימים` + ▾.
- בתוך אזור פתוח: צ'יפים של שולחנות — מספר + קיבולת, ⭐ למתאימים ל-`partySize`,
  טבעת על הנבחר, שולחן תפוס מסומן ומושבת.
- **אזור אחד פתוח בכל רגע** — זה כל העניין של "סדר בעיניים".
- נפתח מראש על האזור של הבחירה הנוכחית; אחרת על האזור הראשון שיש בו התאמה.

צרכנים: `ReservationEditDialog` (במקום ה-`<select>`), וגיליון ה"העבר" של הנייד.

### 2. "העבר" ברשימת הנייד

בכל שורת שולחן **תפוס** ברשימת האזורים מופיע כפתור `🔀` צמוד לשורה.
לחיצה פותחת `Sheet`: "העברת {שם} משולחן {n}" → `ZoneTablePicker` (רק פנויים) → העברה.

לוגיקת ההעברה מורמת מ-`TableDetailsDialog.handleMoveToSpecificTable` לפונקציה
ברמת העמוד, `moveOccupantToTable(fromTableNumber, targetTableNumber)`, כדי ששני
המסלולים ישתמשו באותו קוד: מעדכנת `TableSession.table_number` אם יש session,
ומחליפה את המספר בתוך `Reservation.assigned_table` אם יש הזמנה יושבת.

שולחן פנוי שיש לו הזמנה קרובה מקבל את אותו כפתור — שם הוא מעביר את ההזמנה העתידית.

### 3. פס אחד

```
[+ הזמנה חדשה] [🪑 הושבה מהירה] [⚡ שבץ הכל] │ [📍 אזורים ▾] [🔎 עדשה ▾] ⋯⋯ [⛶] [⋯] [🟢 חי] [שעון]
```

כל השאר בתפריט `⋯` יחיד, בשלוש קבוצות:

- **תצוגה** — שורות בכרטיס (1-6), צבעי אזורים, שרטוט רקע, שכבת AI
- **עריכת מפה** — פתח/נעל, יישר מפה, יישר שורות באזור, הוסף אלמנט, עריכת רשימת שולחנות, שמור מפה
- **הגדרות** — סריקת מפה AI, הגדרות הזמנות, דאשבורד הזמנות, עמוד ציבורי, איפוס מפה (אלנה)

חוקים נלווים:

- **שמור** מופיע בפס רק כשיש שינוי לא־שמור. הזיהוי: השוואת `JSON.stringify` של
  `{tables, facilities, combos}` מול תמונת מצב שנלכדת בטעינה ובכל שמירה מוצלחת.
- כשהמפה **פתוחה לעריכה** מופיע צ'יפ ענבר בפס — "🔓 עריכה פתוחה" + [סיים] — כדי
  שמצב שבו גרירה מזיזה שולחנות לא יישאר דלוק בלי שאף אחד ישים לב.
- מצב **רשימה** מקבל שורה דקה משלו עם "← חזרה למפה" + שמור, כי מחקנו את הכותרת
  שהחזיקה את המתג.
- המקרא שבתחתית המפה מתקפל לצ'יפ "מקרא ▾" שנפתח בלחיצה.

- `ZONE_STYLES` מקודד לשמות של אלנה — עדיין פתוח.
